# Docker — Advanced Level

Now you make containers **production-ready**: small, safe, fast, and easy to watch.

> **In simple words:** production-ready means safe and reliable enough for real users.

## What you will learn
1. Multi-stage builds and small images (Project 1).
2. Run containers as a non-root user (Project 2).
3. Harden containers (read-only, drop powers) (Project 3).
4. Put a reverse proxy in front (Project 4).
5. Add observability: logs, health, metrics (Project 5).
6. Set resource limits and restart policies (Project 6).
7. Ship a full production-ready service (Project 7 — level boss).

## Exit criteria
Finish all 7 projects to complete the **whole Docker track**. Then you are ready for Kubernetes.

**Remember:** Small + safe + watchable = production-ready.

# Docker — Beginner Level

Welcome to Docker! 🐳 Docker lets you pack an app and everything it needs into a **container**.

> **In simple words:** a container is a small, sealed box that holds your app and all it needs to run. It runs the same on any computer.

Why this matters: containers make apps easy to move and run anywhere. This is the base for Kubernetes.

## What you will learn
1. Run and manage containers (Project 1).
2. Work with images (Project 2).
3. Write a Dockerfile to build your own image (Project 3).
4. Use environment variables and volumes (Project 4).
5. Container networking and ports (Project 5).
6. Containerize a simple app (Project 6 — level boss).

## Exit criteria
Finish all 6 projects to complete Docker Beginner. Then Docker Intermediate unlocks.

## Before you start
You need Docker installed. Test it: `docker run hello-world`. If it prints a hello message, you are ready.

**Remember:** Image = the recipe. Container = the running meal made from the recipe.

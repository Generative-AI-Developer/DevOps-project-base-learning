# Docker — Intermediate Level

Now you build **real apps** with many containers working together. This is how real systems run.

> **In simple words:** most real apps are not one container. They are several (web + database + cache) that work as a team.

## What you will learn
1. Run a multi-container app by hand (Project 1).
2. Use Docker Compose to run many containers with one file (Project 2).
3. Build custom networks for a multi-tier app (Project 3).
4. Add persistent storage the right way (Project 4).
5. Add health checks so Docker knows if an app is healthy (Project 5).
6. Debug containers like a pro (Project 6).
7. Build a CI/CD-style image workflow (Project 7 — level boss).

## Exit criteria
Finish all 7 projects to complete Docker Intermediate. Then Docker Advanced unlocks.

**Remember:** Compose is your best friend. One file runs your whole app.

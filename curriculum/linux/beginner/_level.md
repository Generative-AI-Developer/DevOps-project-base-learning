# Linux — Beginner Level

Welcome to Linux! 🐧 This level teaches the basics. You will use the terminal (the black screen where you type commands) like a real Linux user.

> **In simple words:** the terminal is a place where you type commands to tell the computer what to do.

## What you will learn
1. Move around Linux and read files (Project 1).
2. Make and manage files and folders (Project 2).
3. Users, groups, and permissions — who can do what (Project 3).
4. Processes and services — programs that run (Project 4).
5. Install software with a package manager (Project 5).
6. Write your first bash script (Project 6).

## Exit criteria (how you finish this level)
You finish Linux Beginner when **all 6 projects are ✅ Completed**.
Then **Docker Beginner unlocks** for you.

## Order
Do the projects in order: Project 1 → 2 → 3 → 4 → 5 → 6. You cannot skip.

**Remember:** Type the commands yourself. Do not just read. Your hands must learn too.

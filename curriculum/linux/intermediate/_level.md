# Linux — Intermediate Level

Good job finishing Beginner! 🎉 Now you learn **real workflows** — the tasks a junior Linux engineer does every week.

> **In simple words:** here you stop learning single commands, and start building small useful tools.

## What you will learn
1. Build an automated backup system (Project 1).
2. Build a log monitoring script (Project 2).
3. Write your own systemd service (Project 3).
4. Automate tasks with cron and functions (Project 4).
5. Troubleshoot the network (Project 5).
6. Power text processing with grep/sed/awk (Project 6 — level boss).

## Exit criteria
Finish all 6 projects to complete Linux Intermediate. Then Linux Advanced unlocks.

**Remember:** Real engineers automate boring work. That is what this level teaches.

# Linux — Advanced Level

Now you learn **production-style** Linux. This is the level of a real system administrator (sysadmin) and DevOps engineer.

> **In simple words:** production means the real, live system that real users depend on. Mistakes here are costly, so you learn to work safely and carefully.

## What you will learn
1. Write safe, robust bash scripts (Project 1).
2. Control the network and firewall (Project 2).
3. Investigate performance problems (Project 3).
4. Harden a server for security (Project 4).
5. Build a monitoring + alert tool (Project 5).
6. Automate full server administration (Project 6 — level boss).

## Exit criteria
Finish all 6 projects to complete Linux. This finishes the **whole Linux track**. Great job — you now have a strong base for Docker and Kubernetes.

**Remember:** In production, "safe and clear" beats "fast and messy". Always.

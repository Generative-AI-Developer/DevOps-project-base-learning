# Anthropic / Claude — Beginner Level

Welcome to the Anthropic path! 🤖 Here you learn to use **Claude** well. Claude is an AI assistant made by Anthropic.

> **In simple words:** an AI assistant is a computer helper you talk to in normal language. It reads your words and writes an answer.

This path is **independent**. You can do it in parallel with Linux/Docker/Kubernetes. It never blocks them.

## What you will learn
1. Write clear prompts to get good answers (Project 1).
2. Understand Claude models and when to pick which (Project 2).
3. Give Claude a role and rules for better answers (Project 3).
4. Make your first small Claude API call (Project 4).
5. Read and use Claude's reply in a tiny script (Project 5).

> **In simple words:** a **prompt** is the message you send to Claude. A good prompt gives a good answer.

## Exit criteria
You finish this level when **all 5 projects are ✅ Completed**. Then Anthropic Intermediate unlocks.

## Order
Do the projects in order. You cannot skip.

**Remember:** Clear questions get clear answers. Practice writing good prompts.

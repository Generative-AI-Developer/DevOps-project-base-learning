# CCAR-F — Claude Certified Architect, Foundations (Domain Map)

**CCAR-F** checks that you can **design Claude solutions**: system architecture, data privacy, security frameworks, and multi-model deployment.

> ⚠️ **Access note:** the paid exam needs a Claude Partner Network company email (personal Gmail rejected). The course teaches the skills regardless; free Academy certificates are open to all.

## Exam facts (verify officially before booking)
- **Format:** proctored; architecture/design questions. **Time:** ~120 min. **Pass:** 720/1000. **Price:** about $125. Valid ~12 months.

## What it covers
| Area | This level's drill |
|---|---|
| System architecture (RAG, agents, patterns) | Project 1 |
| Data privacy | Project 2 |
| Security frameworks & guardrails | Project 3 |
| Multi-model deployment strategies | Project 4 |
| Full practice test | Project 5 (Mock Exam) |

## How this level works
Each project is a design drill; **Project 5 includes the Mock Exam** (`exams/anthropic/ccar-f/mock-1.md`, graded by `rubric-1.md`), which writes domain scores and applies the weak-area gate before CCAR-P.

**Remember:** CCAR-F is design thinking: choose the right pattern, protect data, secure the system, and use the right models.

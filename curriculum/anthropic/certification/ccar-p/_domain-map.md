# CCAR-P — Claude Certified Architect, Professional (Domain Map)

**CCAR-P** is the **advanced/enterprise** architect cert: complex, large-scale deployments, custom fine-tuning, and infrastructure scaling.

> ⚠️ **Access note:** paid exam needs a Claude Partner Network company email (personal Gmail rejected). The course teaches the skills regardless; free Academy certificates are open to all. This is the **highest** Anthropic cert — it unlocks only after **CCAR-F**.

## Exam facts (verify officially before booking)
- **Format:** proctored; advanced design/scenario questions. **Time:** ~120 min. **Pass:** 720/1000. **Price:** about $175. Valid ~12 months.

## What it covers
| Area | This level's drill |
|---|---|
| Enterprise architecture at scale | Project 1 |
| Reliability & observability | Project 2 |
| Cost governance at scale | Project 3 |
| Customization & advanced deployment (fine-tuning, Managed Agents, batch) | Project 4 |
| Full practice test | Project 5 (Mock Exam) |

## How this level works
Each project is an advanced design drill; **Project 5 includes the Mock Exam** (`exams/anthropic/ccar-p/mock-1.md`, graded by `rubric-1.md`), which writes domain scores and applies the weak-area gate before completion.

**Remember:** CCAR-P is enterprise thinking: scale, reliability, cost governance, and the right advanced tools — all with strong DevOps discipline (which you already have!).

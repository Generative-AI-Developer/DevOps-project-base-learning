# CCDV-F — Claude Certified Developer, Foundations (Domain Map)

**CCDV-F** checks that you can **build apps with Claude**: software-engineering skills, API integration, prompt engineering, and app building.

> ⚠️ **Access note:** the paid exam needs a Claude Partner Network company email (personal Gmail rejected). The course teaches all the skills regardless; free Academy certificates are open to all.

## Exam facts (verify officially before booking)
- **Format:** proctored; knowledge + practical developer questions.
- **Time:** ~120 minutes. **Pass:** 720/1000. **Price:** about $125. Valid ~12 months.

## What it covers
| Area | This level's drill |
|---|---|
| API integration (SDK, Messages API, keys) | Project 1 |
| Prompt engineering + structured output | Project 2 |
| Tool use and agents | Project 3 |
| Evals + cost/performance | Project 4 |
| Full practice test | Project 5 (Mock Exam) |

## How this level works
Each project is a timed developer drill; **Project 5 includes the Mock Exam** (`exams/anthropic/ccdv-f/mock-1.md`, graded by `rubric-1.md`) which writes domain scores and applies the weak-area gate before CCAR-F.

**Remember:** CCDV-F is hands-on building. Know the SDK, prompting, tools, structured output, and how to measure quality and cost.

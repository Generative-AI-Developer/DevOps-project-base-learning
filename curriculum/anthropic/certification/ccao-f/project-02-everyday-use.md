# CCAO-F Drill: Everyday Claude Use and Prompting

**Status:** 🔒 Locked

## 1. Objective
Show you can use Claude well for everyday work tasks with good prompts.

## 2. Real-world scenario
Non-technical staff use Claude daily: emails, summaries, drafts. You must prompt well to get good results fast.

## 3. Skills and concepts you will learn
- Strong everyday prompts (task + context + rules + example).
- Iterating to improve an answer.
- Choosing a good format.

## 4. Prerequisites
- CCAO-F Project 1 completed.
- Read: `study/anthropic/certification/ccao-f/00-ccao-f-guide.md`.

## 5. Step-by-step requirements
1. Pick 3 everyday tasks (e.g. write an email, summarize a report, make a checklist).
2. For each, write a strong prompt (task + context + rules; add an example if useful).
3. Get Claude's answer for each (app or API).
4. Improve one answer with a second, better prompt (iteration). Show the improvement.

## 6. Tasks / challenges
- [ ] 3 strong everyday prompts.
- [ ] 3 good answers.
- [ ] One clear iteration/improvement.

## 7. Expected outcome
You get useful, well-shaped results for real tasks, and you can improve them.

## 8. Acceptance criteria (how I grade it)
Passes only if ALL are true:
1. Each of your 3 prompts has a clear task, context, and at least one rule.
2. You show Claude's answer for each.
3. You show one iteration (a second prompt) that clearly improved an answer.
4. You explain what made the improved prompt better.
5. Simple English throughout.

## 9. Verification checklist
- [ ] 3 prompts + answers.
- [ ] One iteration.
- [ ] Improvement explained.
- [ ] Evidence saved in `submissions/anthropic/certification/ccao-f/project-02/`.

## 10. Common mistakes
- Vague prompts.
- No format rule.
- Not iterating.

## 11. Hints
<details><summary>Hint 1</summary>Recipe: Task / Context / Rules / Example (from Beginner Project 1).</details>
<details><summary>Hint 2</summary>Set the format: "3 bullet points", "under 5 sentences".</details>
<details><summary>Hint 3</summary>Iterate: change one rule and compare.</details>

## 12. Final challenge
Make a small "prompt library": 5 reusable prompt templates for common office tasks. This is a real productivity boost.

## 13. What to submit (evidence)
Save your prompts, answers, and the iteration in `submissions/anthropic/certification/ccao-f/project-02/`. Then say: **"I submit CCAO-F Project 2."**

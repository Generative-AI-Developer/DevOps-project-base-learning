# CCAO-F — Claude Certified Associate, Foundations (Domain Map)

**CCAO-F** is the entry-level Anthropic cert. It checks **foundational generative-AI knowledge and everyday Claude use** — aimed at *non-technical* professionals.

> ⚠️ **Honest access note:** the paid CCAO-F exam (Pearson VUE) currently needs a **company email** in the Claude Partner Network — a personal Gmail is rejected at signup. This course still teaches all the skills and prepares you fully; the free **Anthropic Academy** courses and certificates are open to everyone. Treat the paid exam as an optional, access-gated goal.

## Exam facts (verify on the official Anthropic / Pearson VUE pages before booking)
- **Format:** proctored, mostly multiple-choice (knowledge test).
- **Time:** ~120 minutes.
- **Pass:** 720 on a 100–1000 scale.
- **Price:** about $99. Valid ~12 months.

## What it covers (foundational)
| Area | This level's drill |
|---|---|
| Generative-AI concepts (what an LLM is, tokens, context) | Project 1 |
| Everyday Claude use + good prompting | Project 2 |
| Responsible and safe use | Project 3 |
| Full practice test | Project 4 (Mock Exam) |

## How this level works
- Each project is a short knowledge + practice drill.
- **Project 4 includes the Mock Exam** (`exams/anthropic/ccao-f/mock-1.md`, graded by `rubric-1.md`), which writes **domain scores** to `progress.json`. A weak area (< 0.66) must be improved before CCDV-F.

**Remember:** CCAO-F is knowledge-first. Learn the words and the safe, smart way to use Claude.

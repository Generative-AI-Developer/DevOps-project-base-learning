# Anthropic / Claude — Advanced Level

Now you build **agents** and **real systems** with Claude — the top developer and architect skills.

> **In simple words:** an agent is a program where Claude works in steps, using tools, until a job is done.

## What you will learn
1. Agents — Claude works in a loop with tools (Project 1).
2. MCP — connect Claude to outside tools and data (Project 2).
3. RAG — give Claude the right facts to answer from (Project 3).
4. Safety and guardrails — keep the app safe (Project 4).
5. Cost and performance tuning (Project 5).
6. Build an end-to-end agent (Project 6 — level boss).

## Exit criteria
Finish all 6 projects to complete Anthropic Advanced. Then the Anthropic Certification Level unlocks (CCAO-F → CCDV-F → CCAR-F → CCAR-P).

**Remember:** Start simple. Use an agent only when the task really needs many steps and tools.

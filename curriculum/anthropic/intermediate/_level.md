# Anthropic / Claude — Intermediate Level

Now you go from "talk to Claude" to "build real features with Claude".

> **In simple words:** you learn the tools that turn Claude into a real app: better prompts, tool use, JSON output, streaming, caching, and testing.

## What you will learn
1. Deeper prompt engineering (examples, structure) (Project 1).
2. Tool use — let Claude call your code (Project 2).
3. Structured output — get clean JSON (Project 3).
4. Streaming — show the answer as it types (Project 4).
5. Prompt caching — save money and time (Project 5).
6. Simple evals — measure if your app is good (Project 6 — level boss).

## Exit criteria
Finish all 6 projects to complete Anthropic Intermediate. Then Anthropic Advanced unlocks.

## Before you start
You need your API key set (from Beginner Project 4) and the `anthropic` SDK installed.

**Remember:** These are the building blocks of every real Claude app. Learn them well.

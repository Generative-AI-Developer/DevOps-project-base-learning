# Everyday Polite Phrases

**Status:** 🔒 Locked (unlocks after Lesson 1)

## 1. Objective
Learn to be polite in English: ask for things kindly and reply nicely.

## 2. Real-world scenario
At work you must ask people for help many times a day. Polite words make them happy to help you.

## 3. Skills and concepts you will learn
- Polite words: please, thank you, sorry, excuse me.
- Soft requests: "Could you…?" and "May I…?".
- Kind replies: "You're welcome", "No problem".

## 4. Prerequisites
- Lesson 1 completed.
- Read: `study/english/beginner/02-polite-phrases.md`.

## 5. Step-by-step requirements
1. Read the lesson and vocabulary.
2. Write **3 polite requests** using "Could you…" or "May I…".
3. Write a short **conversation** (5–6 lines) where you politely ask a colleague for help and thank them.

## 6. Tasks / challenges
- [ ] 3 polite requests written.
- [ ] Use at least **5 words** from today's list.
- [ ] A 5–6 line polite conversation.
- [ ] Use "please", "thank you", and one reply ("You're welcome"/"No problem").

## 7. Expected outcome
You can ask for help politely and reply kindly, using the new words.

## 8. Acceptance criteria (how I grade it)
Passes if ALL are true:
1. You wrote 3 requests, each using "Could you…" or "May I…" (and "please").
2. You used at least **5 vocabulary words** from the lesson.
3. Your conversation includes a polite request, a "thank you", AND a reply.
4. The English is understandable (small mistakes OK — I'll help).

## 9. Verification checklist
- [ ] 3 polite requests.
- [ ] 5+ new words.
- [ ] Conversation with request + thanks + reply.
- [ ] Saved in `submissions/english/beginner/project-02/`.

## 10. Common mistakes
- "Give me…" (rude) → "Could you give me…, please?"
- Saying "sorry" too much → use "excuse me" to get attention.
- Forgetting the reply to "thank you".

## 11. Hints
<details><summary>Hint 1</summary>Requests: "Could you help me, please?", "May I ask a question?", "Could you send the file, please?"</details>
<details><summary>Hint 2</summary>Use these words: please, thank you, help, sure, appreciate.</details>
<details><summary>Hint 3</summary>End with: "Thank you so much." → "You're welcome. No problem."</details>

## 12. Final challenge
Write one line where you politely say "no" to a request. Example: "Sorry, I can't right now, but I can help later."

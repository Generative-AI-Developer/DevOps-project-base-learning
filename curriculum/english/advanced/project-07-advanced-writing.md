# Advanced Email and Written Communication

**Status:** 🔒 Locked

## 1. Objective
Learn to choose the right tone and formality, and write clear, professional messages.

## 2. Real-world scenario
You must write the same request two ways: a quick note to a close teammate, and a formal email to a client. You also fix an unclear message.

## 3. Skills and concepts you will learn
- Matching tone to the reader.
- Formal vs informal writing.
- Clarity and proofreading.

## 4. Prerequisites
- Advanced Lesson 6 completed.
- Read: `study/english/advanced/07-advanced-writing.md`.

## 5. Step-by-step requirements
1. Write the **same message** two ways: one **informal** (to a teammate) and one **formal** (to a client/manager).
2. Take one long, unclear sentence and **rewrite it clearly** into 2–3 short sentences.
3. Write one line explaining **who** each version is for and **why** the tone fits.

## 6. Tasks / challenges
- [ ] An informal version and a formal version of the same message.
- [ ] A clear rewrite of an unclear sentence.
- [ ] A note on audience/tone choice.
- [ ] Use at least **7 words** from today's list.
- [ ] Soften the formal one with could/would/kindly.

## 7. Expected outcome
You can write the right tone for any reader, clearly and correctly.

## 8. Acceptance criteria (how I grade it)
Passes if ALL are true:
1. You show the same message in **informal** and **formal** versions, and both are appropriate.
2. The formal version uses polite softeners (could/would/kindly).
3. You rewrite an unclear sentence into clear, short sentences.
4. You explain who each version is for and why.
5. You use at least **7 vocabulary words** from the lesson, with no obvious careless typos (proofread!).

## 9. Verification checklist
- [ ] Informal + formal versions.
- [ ] Clear rewrite.
- [ ] Audience/tone note.
- [ ] Saved in `submissions/english/advanced/project-07/`.

## 10. Common mistakes
- Too casual to a manager.
- Long, unclear sentences.
- Typos (always proofread).

## 11. Hints
<details><summary>Hint 1</summary>Informal: "Hi Sara, can you send the file today? Thanks!"</details>
<details><summary>Hint 2</summary>Formal: "Dear Ms. Fatima, I would be grateful if you could send the file today. Best regards, ___."</details>
<details><summary>Hint 3</summary>Clarity: one idea per sentence; cut extra words.</details>

## 12. Final challenge
Proofread your own two versions carefully and list any 2 mistakes you found and fixed (spelling, grammar, or tone).

## 13. What to submit (evidence)
Save both versions + the rewrite + your note in `submissions/english/advanced/project-07/`. Then say: **"I submit English Advanced Project 7."**

---
**Remember:** Match tone to the reader, keep it clear and concise, soften formal requests, and always proofread.

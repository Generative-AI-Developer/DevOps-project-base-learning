# CCAO-F Mock Exam 1 (Practice Questions)

## How this works
1. Set a timer for **60 minutes**.
2. Answer all questions. This is mostly multiple-choice (knowledge).
3. The mentor grades with `rubric-1.md` and writes your domain scores.
4. Pass line: **72%** (like the real 720/1000). Weak areas (< 0.66 in a domain) must be improved before CCDV-F.

> These are original practice questions in the exam style — not real exam questions.

## Part A — Generative-AI concepts (domain: genai-concepts)
1. What is a token? (a) a password (b) a small piece of text (c) a model (d) a file
2. What is the context window? (a) the app screen (b) how much text the model reads at once (c) the price (d) the internet
3. A "hallucination" is when the model... (a) crashes (b) is confidently wrong (c) is slow (d) refuses
4. Which model is usually cheapest? (a) Opus (b) Sonnet (c) Haiku (d) they cost the same
5. Which is TRUE? (a) AI is always right (b) AI can be biased and should be checked (c) AI never needs review (d) AI cannot write text

## Part B — Everyday use & prompting (domain: everyday-use)
6. A strong prompt usually has... (a) only a task (b) task + context + rules (c) just "help me" (d) many questions at once
7. Best way to get consistent format? (a) hope (b) give examples + a format rule (c) use a bigger model only (d) ask twice
8. "Iterating" a prompt means... (a) giving up (b) improving the prompt and trying again (c) using more models (d) copying the answer
9. To keep an answer short you should... (a) say nothing (b) add a length rule (c) use Opus (d) send more text
10. Where does the task go? (a) the system prompt only (b) the user message (c) nowhere (d) the model name

## Part C — Responsible use (domain: responsible-use)
11. You should NOT paste into an AI tool... (a) a public article (b) a customer's password (c) a math question (d) a recipe
12. For a medical decision, you should... (a) trust the AI fully (b) have a qualified human review (c) skip it (d) use Haiku
13. Which reduces hallucination risk? (a) ask it to guess (b) give it the real facts (RAG) and check (c) use no context (d) raise the price
14. Bias in AI means... (a) it is fast (b) it can unfairly favor or harm some groups (c) it is cheap (d) it is offline
15. A good rule for teams is... (a) never check outputs (b) share all secrets (c) review important outputs and protect private data (d) always use the biggest model

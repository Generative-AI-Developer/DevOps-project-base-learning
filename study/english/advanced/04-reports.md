# Study: Writing Reports and Documentation

At work you sometimes write **reports** and **documents**. This lesson gives you the structure and words to write them clearly.

## 1. Easy explanation
A report is a clear, organized document. It has **sections** with **headings**: an introduction, the **findings** (what you learned), a **conclusion**, and **recommendations** (what to do). Keep it **clear**, **concise** (short), and **accurate** (correct).

## 2. Words to know (vocabulary)
| Word | English meaning (simple) | Urdu (اردو) |
|------|--------------------------|-------------|
| report | an organized written account | رپورٹ |
| document | a formal piece of writing | دستاویز |
| introduction | the opening part | تعارف |
| background | the situation before | پس منظر |
| findings | what you discovered | نتائج / معلومات |
| data | numbers and facts | اعداد و شمار / ڈیٹا |
| analysis | studying the data | تجزیہ |
| conclusion | the final result/idea | نتیجہ |
| recommendation | advice on what to do | سفارش |

| evidence | proof / support | ثبوت |
| appendix | extra material at the end | ضمیمہ |

## 3. Useful phrases (ready to use)
- The **purpose** of this report is **[objective]**.
- This report **covers [topic]**.
- The main **findings** are **[points]**.
- **Based on the data**, **[result]**.
- In **conclusion**, **[main idea]**.
- We **recommend** **[action]**.

## 4. A sample report outline
```
Title: Monthly Website Report — June

1. Introduction
   - Purpose: to review website visits in June.

2. Findings
   - Visits rose by 20%.
   - Most visitors came from mobile phones.

3. Analysis
   - The rise came after the new homepage.

4. Conclusion
   - The new homepage improved visits.

5. Recommendations
   - Continue mobile-first design.
   - Add more homepage content.
```

## 5. Small grammar tip — formal, impersonal tone
Reports often use **passive voice** and avoid "I think":
- Instead of "I collected the data" → "The data **was collected** in June."
- Instead of "I think it's good" → "**The data shows** a positive result."

## 6. Practice — say it and write it
1. Write section headings for a short report (4–5 headings).
2. Write a purpose line and one finding.
3. Turn "I think sales went up" into a report-style sentence.

## 7. Common mistakes (and the fix)
- ❌ No headings; one long block. → ✅ Use clear **headings** and **sections**.
- ❌ Too long. → ✅ Be **concise** — short sentences, key points only.
- ❌ "I think…" everywhere. → ✅ "The data shows…", "Based on the results…".

## 8. Tips to remember
- Structure: **Intro → Findings → Analysis → Conclusion → Recommendations**.
- Use **headings** so readers can scan quickly.
- Support claims with **evidence** (data).

## 9. Practice questions / tasks
1. Name three sections of a report.
2. Write a purpose line for a report.
3. Make formal: "I think we should hire more people."

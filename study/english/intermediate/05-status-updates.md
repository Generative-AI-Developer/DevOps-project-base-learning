# Study: Giving Updates and Status Reports

Managers always want to know: "How is it going?" This lesson helps you give a clear update on your work.

## 1. Easy explanation
A **status update** tells people where your work is: what is **done**, what is **in progress**, what is **pending**, and the **next steps**. Keep it short and clear.

## 2. Words to know (vocabulary)

|------|--------------------------|-------------|

| progress | forward movement | پیش رفت |
| status | the current state | حالت / صورتحال |
| complete | fully done | مکمل |
| in progress | being done now | جاری |
| pending | waiting; not started/finished | زیرِ التوا / باقی |
| delay | being late | تاخیر |
| on track | going as planned | درست سمت میں |
| behind schedule | later than planned | شیڈول سے پیچھے |

## 3. Useful phrases (ready to use)
- Here's a quick **update**.
- The task is **complete / in progress / pending**.
- We're **on track** for Friday.
- We're a bit **behind schedule** because of **[reason]**.
- The **blocker** is **[problem]**.
- **Next steps** are **[actions]**.
- I **estimate** two more days.

## 4. A sample status update
```
Subject: Project Status — Week 3

Hi team,

Quick update:
- Done: design and database setup are complete.
- In progress: the login page (about 70% done).
- Pending: testing.
- Blocker: we are waiting for the API key from IT.
- Next steps: finish login, then start testing.

We are mostly on track. I estimate we finish by Friday.

Best regards,
Ali
```

## 5. Small grammar tip — "done" things use present perfect
For finished work, use **have/has + past participle**:
- "I **have finished** the design." · "We **have completed** testing."
For status now, use present simple: "The task **is** in progress."

## 6. Practice — say it and write it
1. Say 3 times: "The design is complete. The login page is in progress. Next steps are testing."
2. Write a 5-line status update for a real task.
3. Write one line about a blocker and one about next steps.

## 7. Common mistakes (and the fix)
- ❌ "I finish the report." (for a done task) → ✅ "I **have finished** the report."
- ❌ No next steps. → ✅ Always add "**Next steps** are…".
- ❌ Unclear status. → ✅ Use **done / in progress / pending**.

## 8. Tips to remember
- Structure: **Done → In progress → Pending → Blocker → Next steps**.
- Keep it to **5–6 short lines**.
- Give an **estimate** for the finish time.

## 9. Practice questions / tasks
1. Fix: "I complete the design yesterday."
2. Give a status for a task not yet started.
3. Write a "next steps" line.
